# Austria area hierarchy

Interactive map and tables of the Austrian PLZ / nanobrick / macrobrick / standardregion / Bundesland hierarchy.

- `app/` – the map application (static, Leaflet)
- `deliverables/` – TopoJSON, CSV keys and relation tables, QA report (see `deliverables/README.md`)

Boundaries derived from PLZ polygons © OpenStreetMap contributors, ODbL.
